# Security policy

SoundRip is a static, browser-only application. It does not send selected files to a server.

If you discover a security issue in the application code, do not publish exploit details in a public issue first. Contact the repository maintainer privately and include:

- a clear description of the issue;
- affected browser and version;
- reproducible steps; and
- the possible impact.

Do not attach sensitive media files. A small synthetic sample or a description is sufficient.
